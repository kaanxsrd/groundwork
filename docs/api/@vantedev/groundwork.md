# @vantedev/groundwork

groundwork: Postgres-only, Drizzle-native building blocks for rate limiting, audit logs,
scoped API keys, background jobs and idempotency keys.

```ts
import { createGroundwork } from "@vantedev/groundwork";
import * as tables from "./db/schema/groundwork";

export const gw = createGroundwork({
  db,
  tables,
  secret: env.GROUNDWORK_SECRET,
  audit: { actions: ["post.create", "post.update"] },
  apiKeys: { namespace: "vnt", scopes: { "posts:read": "Read posts" } },
});
const loginLimit = gw.rateLimit.rule({ name: "login:ip", limit: 5, window: "15m" });
await gw.audit.record({ actor: { type: "system" }, action: "post.create" });
const auth = await gw.apiKeys.verify(request, { scopes: ["posts:read"] });
return gw.idempotency.handle(request, { scope: `apikey:${auth.key.id}` }, () => createPost());
```

##### stackTraceLimit

> `static` **stackTraceLimit**: `number`

The `Error.stackTraceLimit` property specifies the number of stack frames
collected by a stack trace (whether generated by `new Error().stack` or
`Error.captureStackTrace(obj)`).

The default value is `10` but may be set to any valid JavaScript number. Changes
will affect any stack trace captured _after_ the value has been changed.

If set to a non-number value, or set to a negative number, stack traces will
not capture any frames.

###### Inherited from

`Error.stackTraceLimit`

#### Methods

##### captureStackTrace()

> `static` **captureStackTrace**(`targetObject`, `constructorOpt?`): `void`

Creates a `.stack` property on `targetObject`, which when accessed returns
a string representing the location in the code at which
`Error.captureStackTrace()` was called.

```js
const myObject = {};
Error.captureStackTrace(myObject);
myObject.stack;  // Similar to `new Error().stack`
```

The first line of the trace will be prefixed with
`${myObject.name}: ${myObject.message}`.

The optional `constructorOpt` argument accepts a function. If given, all frames
above `constructorOpt`, including `constructorOpt`, will be omitted from the
generated stack trace.

The `constructorOpt` argument is useful for hiding implementation
details of error generation from the user. For instance:

```js
function a() {
  b();
}

function b() {
  c();
}

function c() {
  // Create an error without stack trace to avoid calculating the stack trace twice.
  const { stackTraceLimit } = Error;
  Error.stackTraceLimit = 0;
  const error = new Error();
  Error.stackTraceLimit = stackTraceLimit;

  // Capture the stack trace above function b
  Error.captureStackTrace(error, b); // Neither function c, nor b is included in the stack trace
  throw error;
}

a();
```

> `readonly` **secret**: [`SecretSource`](#secretsource)

## Type Aliases

### Duration

> **Duration** = `` `${number}${DurationUnit}` ``

A length of time written as a number and a unit: `"500ms"`, `"30s"`, `"15m"`, `"24h"`, `"90d"`, `"2w"`.

Bare numbers are not accepted, so `60` can never be misread as seconds when milliseconds were meant.
Build one from a variable with a template literal: `` `${days}d` ``.

***

### DurationUnit

> **DurationUnit** = `"ms"` \| `"s"` \| `"m"` \| `"h"` \| `"d"` \| `"w"`

Units accepted in a [Duration](#duration). Months and years are left out because their length varies.

***

### GroundworkErrorCode

> **GroundworkErrorCode** = `"invalid_config"` \| `"invalid_argument"`

Machine-readable reason for a [GroundworkError](#groundworkerror).

- `invalid_config`: options passed when creating a module are wrong. Thrown at startup.
- `invalid_argument`: a value passed to a method is wrong (for example a malformed duration).

***

### LogContext

> **LogContext** = `Readonly`\<`Record`\<`string`, `unknown`\>\>

Structured context attached to a log line. groundwork never puts secrets, raw keys or raw subjects in it.

***

### PreviousSecretsSource

> **PreviousSecretsSource** = readonly [`Secret`](#secret-1)[] \| (() => readonly [`Secret`](#secret-1)[])

Secrets used before the current one, newest first, or a function that returns them on first
use. API keys and idempotency keys stored under one of them are still recognised, so the secret
can change without invalidating them. Each must be at least 32 bytes, like the secret.

***

### Secret

> **Secret** = `string` \| `Uint8Array`

The app secret, as a string (UTF-8) or raw bytes. It must be at least 32 bytes long.

***

### SecretSource

> **SecretSource** = [`Secret`](#secret-1) \| (() => [`Secret`](#secret-1))

The secret, or a function that returns it. A function is called on first use (the first check,
key hash or idempotency claim), so code that only cleans up, prunes or runs jobs never needs
it, and the environment can be read after `next build`.
